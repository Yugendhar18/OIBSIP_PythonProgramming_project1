# 🧮 BMI Calculator (Python)

This is a simple command-line Body Mass Index (BMI) calculator built with Python. It takes user input for weight and height, calculates the BMI, and provides a health classification based on the result.

## 🚀 Features

- Accepts user input for weight (kg) and height (cm or m)
- Calculates BMI using the standard formula
- Classifies BMI into categories (Underweight, Normal, Overweight, Obese)
- Beginner-friendly code with clear structure

## 📌 BMI Formula



\[
BMI = \frac{weight\ (kg)}{height\ (m)^2}
\]



## 🛠️ Technologies Used

- Python 3
- Command Line Interface (CLI)
- Basic control flow and math operations
